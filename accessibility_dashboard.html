Core barrier

Meaningful content is embedded in raster page images.

OCR may make words discoverable, but it does not by itself create headings, table structure, reading order, or label/value relationships.

Preferred outcome: Publish an accessible HTML record and retain the scan as the original-record download.

Recommended remediation

Preferred solution: accessible HTML record

  1. Use a descriptive page title and one primary heading.
  2. Organize content under logical section headings.
  3. Use definition lists for simple label/value information.
  4. Use data tables only for meaningful row and column relationships.
  5. Provide meaningful text for approval and signature information.
  6. Treat seals as decorative where they add no information.
  7. Retain the scan as a clearly labeled secondary format.

Possible regulatory exception

POTENTIAL REGULATORY EXCEPTION – LEGAL REVIEW REQUIRED

Because the certificate was issued September 3, 2021, a preexisting-conventional-electronic-document exception might be relevant. Age alone does not establish the exception.

Questions requiring confirmation

  • Where is the PDF currently published?
  • Is it returned through a public property or permit search?
  • Is it needed for a sale, lease, permit, inspection, financing, or another current service?
  • Is it stored in a dedicated archive or an active records system?
  • Is access public or password protected?
  • Has the file been altered since archiving?

Even if an exception applies, an accessible format may still need to be provided upon request. Legal review should confirm applicability.
